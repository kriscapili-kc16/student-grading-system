# Web-Based Student Grading System

A full-stack web application built to modernize traditional database systems (e.g., MS Access) into a web architecture using Python, FastAPI, SQLite, and vanilla JavaScript.

## Features
- **RESTful API Backend:** Built with FastAPI and Pydantic for data validation.
- **Persistent Storage:** SQLite database integration with auto-table initialization.
- **Dynamic Frontend Dashboard:** Responsive UI using modern CSS Grid and standard web API `fetch()` operations.
- **Automatic Score Calculation:** Backend compute engine for subject averages and total percentages.

## Tech Stack
- **Frontend:** HTML5, CSS3 (Grid Layout), Modern JavaScript (ES6+ async/await)
- **Backend:** Python 3, FastAPI, Uvicorn
- **Database:** SQLite3
